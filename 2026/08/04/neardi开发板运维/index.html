扩大根分区

操作步骤（在外部Linux系统中执行）

1. 查看当前分区情况（可选）

此步骤是为了确认分区信息，方便核对。

2. 卸载 oem 和 userdata 分区

确保这两个分区没有被挂载。

3. 删除 oem 和 userdata 分区

使用 fdisk 工具删除分区 7 和 8。

进入交互界面后：

  • 输入 d，然后输入 8，删除分区 8 (userdata)。
  • 再次输入 d，然后输入 7，删除分区 7 (oem)。
  • 输入 w 保存并退出。

4. 调整 rootfs 分区大小

使用 parted 将根分区 (分区 6) 扩展到剩余的全部空间。

进入交互界面后：

  • 输入 unit s 将单位设置为扇区。
  • 输入 resizepart 6 100%，将分区 6 扩展到磁盘的剩余所有空间。
  • 输入 quit 退出。

5. 使 rootfs 分区生效

分区调整后，需要同步调整文件系统的大小。

6. 修改 fstab 文件

这是至关重要的一步，否则系统重启时会因找不到 oem 和 userdata 分区而报错。
